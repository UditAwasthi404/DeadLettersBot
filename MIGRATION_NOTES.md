## Benchmarks

Measured 2026-11-28 on Windows (`win32`, Node v24.22.1). Electron cold-start script includes Playwright launch overhead and a warm Vite server on `:5173`.

| Metric | Before (main / prior image) | After (this branch) | Script / method |
| --- | --- | --- | --- |
| Cold start → interactive (median of 3) | n/a (first baseline) | **6538.9 ms** | `node bench/desktop-launch.mjs m1-baseline` |
| Electron Browser process RSS | n/a | **137.4 MiB** | same bench sample |
| Electron all processes RSS | n/a | **616.1 MiB** | Browser+GPU+Utility+Tab |
| Warm `ensure-browser` | n/a | **3152.5 ms** | timed `docker exec … agentos-ensure-browser` |
